1

Stage 1: News Article Input & Ingestion

Users paste article text into our secure web interface. The frontend enforces strict validation (minimum 5 words to prevent arbitrary short-circuiting, maximum 40,000 characters to protect memory). The raw string is transmitted over a secure JSON POST request to the Flask /predict API endpoint.

2

Stage 2: Deterministic Text Preprocessing

Academic fake news detection faces a well-documented pitfall: models that memorize news agency tags (e.g. "WASHINGTON (Reuters) -") achieve artificially high test scores without learning stylistic deception. Our clean_text() pipeline strips news agency datelines, removes URLs, filters HTML tags, removes special characters, and lowercases text so the model focuses purely on semantic veracity.

Dateline Stripping • Lowercasing • URL Removal • Punctuation Filtering
3

Stage 3: TF-IDF Feature Extraction

The cleaned text is transformed using Term Frequency-Inverse Document Frequency (TF-IDF) with sublinear term-frequency scaling. We extract unigrams and bigrams across a vocabulary of 15,000 top features with min_df=3 and max_df=0.85. Bigram extraction ensures that contextual phrases like "breaking secret" or "anonymous source" are given proper statistical weight.

15,000 Vocabulary • Unigram (1) & Bigram (2) • Sublinear TF
4

Stage 4: Calibrated Machine Learning Classification

The high-dimensional feature vector is passed to our trained Support Vector Machine (LinearSVC) and Logistic Regression architectures. While standard SVM produces only uncalibrated hyperplane distances, we implement Platt scaling via CalibratedClassifierCV using 3-fold cross validation. This transforms geometric margins into mathematically sound, calibrated posterior probabilities.

LinearSVC • Platt Scaling • Logistic Regression Benchmark
5

Stage 5: Prediction Confidence, Linguistic Diagnostics & SQLite Audit

The final prediction returns the winning class (REAL or FAKE) with its calibrated confidence percentage. In parallel, our feature extraction engine scans for sensationalist linguistic markers (uppercase ratio, exclamation density, readability index) to construct an explainable diagnostic paragraph, and logs the prediction to SQLite.

Calibrated Probability • Linguistic Signals • SQLite Persistence
